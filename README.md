# Colored Seeds website

Home page, Privacy Policy and Terms of Service of the Colored Seeds game for Android, in English
and Russian, published with GitHub Pages at <https://alexeyw.github.io/colored-seeds/>.

| Page | English | Russian |
|------|---------|---------|
| Home | `/` | `/ru/` |
| Privacy Policy | `/privacy.html` | `/ru/privacy.html` |
| Terms of Service | `/terms.html` | `/ru/terms.html` |

Plain HTML and one stylesheet; no build step, no scripts, no trackers.

The game's source code is in a private repository; this folder is maintained there (`site/`) and
copied to the public `alexeyw/colored-seeds` repository, which serves it from the `main` branch.

The site root, https://alexeyw.github.io/, is the separate `alexeyw/alexeyw.github.io` repository:
it redirects here and holds the Search Console verification file that the Google Cloud OAuth
branding relies on.
